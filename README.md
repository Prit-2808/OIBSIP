# OIBSIP — Web Development & Designing Internship

This repository showcases the projects I completed during my **Web Development and Designing Internship at Oasis Infobyte (OIBSIP)**. It highlights hands-on experience in responsive web design, UI development, and front-end technologies — HTML, CSS, and JavaScript.

## 📌 About the Internship
OIBSIP is a project-based internship program focused on building real-world web applications from scratch. Each task strengthened a different aspect of front-end development — from UI logic and DOM manipulation to layout design and client-side data handling.

## 🗂️ Projects

| Task | Project | Description | Tech Stack |
|------|---------|-------------|------------|
| 1 | [Calculator Web App](./Task1-Calculator) | A fully functional calculator with light/dark mode, live history, and all basic arithmetic operations. | HTML, CSS, JavaScript |
| 2 | [Elon Musk Tribute Page](./Task2-TributePage) | A responsive tribute page with hero section, achievements, quotes, and a career timeline. | HTML, CSS |
| 3 | [DayList — To-Do App](./Task3-ToDoApp) | A task manager with Pending/Completed lists, edit/delete, timestamps, and localStorage persistence. | HTML, CSS, JavaScript |
| 4 | [HomeDecor — Auth System](./Task4-AuthSystem) | A login/register system with a secured dashboard, session handling, and real-time alerts. | HTML, CSS, JavaScript |


## 🛠️ Skills Demonstrated
- Responsive UI/UX design (Flexbox, CSS Grid)
- DOM manipulation & event handling
- Client-side data persistence (localStorage, sessionStorage)
- Form validation and user authentication flows
- Clean, modern styling with CSS custom properties (variables)
- Building real-world, functional web applications from scratch

## 🚀 How to Run Any Project
1. Open the respective task folder.
2. Open `index.html` in any modern browser.
3. No build tools or installation required — pure HTML/CSS/JS.
