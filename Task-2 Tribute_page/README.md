# Task 2 — Elon Musk Tribute Page

## Objective
Create a tribute page for a person you admire using HTML and CSS, with an appealing layout, organized content sections, images/background, and good typography.

## Steps Performed
1. Structured the page with semantic HTML sections: Hero, About, Achievements, Quotes, Timeline, and Reference.
2. Built a fixed navbar with anchor links for smooth scrolling to each section.
3. Designed a hero section with a full-screen background image and dark overlay gradient for text readability.
4. Used CSS Grid (`auto-fit`, `minmax`) to create responsive card layouts for Achievements and Quotes.
5. Built a vertical timeline (1995–2022) highlighting key career milestones, styled with left-border accents.
6. Added hover effects on cards and timeline items for interactivity.
7. Added a "Learn More" reference section linking to the full Wikipedia biography.
8. Made the layout fully responsive using a media query for mobile screens (stacked nav, smaller headings).

## Tools & Technologies Used
- **HTML5** — semantic structure (header, nav, section, footer)
- **CSS3** — Grid, Flexbox, gradients, hover transitions, media queries
- **Google Fonts (Poppins)** — typography
- **Unsplash** — hero background image

## Outcome
A fully responsive, single-page tribute site with smooth scroll navigation, a clean dark theme (navy background with cyan accents), organized content sections, and a timeline showcasing career milestones. The design works well across desktop and mobile screen sizes.

## How to Run
1. Download/clone this repository.
2. Open `index.html` in any modern browser.
3. No installation or build steps required — pure HTML/CSS.

## Files
- `index.html` — Page structure and content
- `style.css` — Styling, layout, responsiveness, and theme
